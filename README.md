# DriverDrowsinessDetectionWinApp
Sürücü Yorgunluk Tespit Sistemi göz hareketlerini ve yüz ifadelerini analiz ederek sürücü yorgunluğunu gerçek zamanlı tespit eder. PyQt5, OpenCV ve Firebase ile geliştirilen sistem; mola uyarısı, oturum yönetimi ve detaylı raporlar sunarak sürüş güvenliğini artırır.
